# Implementation Plan

- [x] 1. 開発環境の準備
- [x] 1.1 ローカル開発環境と最小構成を準備する
  - Go 1.25 のローカル実行環境を用意する
  - Node LTS + Vite + React + TypeScript の最小構成を用意する
  - WebSocket ライブラリの利用準備を行う
  - ローカルASR/LLM/TTSを起動できる状態を用意する
  - Docker実行環境を用意し、docker-compose で起動できることを確認する
  - _Requirements: 1.1, 4.1, 4.2, 4.3, 9.1_

- [x] 2. 双方向通信チャネルとセッション管理
- [x] 2.1 (P) サーバ側の双方向チャネルとセッションライフサイクルを実装する
  - RFC1918 + localhost の境界ポリシーを適用し、接続確立時に境界ステータスを送信する
  - 開始/停止、発話開始/終了、音声チャンク、キャンセル、PING/PONGを受信・処理する
  - セッション状態とgenerationIdを管理し、切断時の通知と再接続時の継続方針を適用する
  - _Requirements: 2.3, 2.4, 9.2, 9.3, 9.4, 9.5, 11.1, 11.2, 11.4_

- [x] 2.2 (P) ブラウザ側の双方向チャネルとイベント送受信を実装する
  - ローカルエンドポイントへ接続し、再接続時にセッションを継続する
  - 音声チャンクと制御イベントを送信する
  - サーバイベントを受信し、UI/再生/状態更新へ伝播する
  - _Requirements: 9.1, 9.2, 9.3, 9.4, 9.5_

- [ ] 3. UI/UX と状態表示
- [ ] 3.1 チャットログと状態表示のUIを実装する
  - 文字起こしと応答メッセージを時系列で表示する
  - 状態（Idle/Listening/Thinking/Speaking）を表示する
  - _Requirements: 6.1, 6.2, 6.3, 6.4_

- [ ] 3.2 開始/停止フローと権限・自動再生制約の案内を実装する
  - 開始操作でマイク権限の取得とセッション開始を実行する
  - 停止操作で音声入力と再生を停止する
  - 権限拒否や自動再生制約時の案内を表示する
  - _Requirements: 2.1, 2.2, 2.4, 2.5, 10.1, 10.2, 10.3, 10.4, 10.5_

- [ ] 3.3 通信境界の表示と音声再生UIを実装する
  - RFC1918 + localhost の境界範囲を表示する
  - 最新応答の音声を再生・ダウンロードできるようにする
  - _Requirements: 11.5, 4.4_

- [ ] 3.4 エラー表示と復旧導線を実装する
  - エラー内容と対処方法をユーザーに提示する
  - 再試行の導線と安全な終了を提供する
  - _Requirements: 6.5, 7.1, 7.2, 7.3, 7.4, 7.5_

- [ ] 4. 音声入力とVAD
- [ ] 4.1 ハンズフリー音声入力と発話開始/終了検知を実装する
  - セッション中の連続入力に対応する
  - 発話区間の開始/終了を検知し通知する
  - 失敗時はユーザーへ通知する
  - _Requirements: 3.1, 3.2, 3.3, 3.4, 3.5_

- [ ] 4.2 音声チャンク化とセッション連動の送信を実装する
  - セッション有効時のみ音声を送信する
  - 停止時は送信を中断する
  - _Requirements: 2.3, 2.5, 3.2, 3.3_

- [ ] 5. 音声再生と割り込み
- [ ] 5.1 応答音声の再生パイプラインを実装する
  - 単一ストリームの再生と即時停止に対応する
  - 自動再生制約に配慮した再生開始を行う
  - _Requirements: 5.1, 10.3, 10.4_

- [ ] 5.2 割り込み（barge-in）処理を実装する
  - ユーザー発話開始で即時停止し、キャンセルを送信する
  - 新しい発話を優先し、古い応答は再生しない
  - _Requirements: 5.1, 5.2, 5.3, 5.4, 5.5_

- [ ] 6. ASR/LLM/TTS アダプタとパイプライン
- [ ] 6.1 (P) ローカルASRアダプタを実装する

  - _Requirements: 1.1, 4.1_

- [ ] 6.2 (P) ローカルLLMアダプタとキャンセル処理を実装する

  - _Requirements: 1.1, 4.2, 5.2_

- [ ] 6.3 (P) ローカルTTSアダプタを実装する
  - 応答テキストを再生可能な音声形式で出力する
  - _Requirements: 1.1, 4.3, 4.4_

- [ ] 6.4 パイプライン統合と会話履歴の管理を実装する

  - 会話履歴を保持して応答生成に利用する
  - _Requirements: 4.1, 4.2, 4.3, 4.4, 4.5, 5.3, 5.4_

- [ ] 7. 通信境界ポリシー
