# UI設計（暫定）

## 目的
- 最小構成で音声対話を開始/停止できること
- 状態（待機/収録/処理/再生）と通信境界（RFC1918 + localhost）を明示すること
- エラー時に復旧導線を示すこと

## 画面一覧
- **メイン画面（単一ページ / チャット形式）**
  - Start/Stop 操作
  - 状態表示（Listening / Thinking / Speaking）
  - 通信境界の表示
  - チャットログ（文字起こし・応答）
  - 合成音声の再生/ダウンロード
  - エラー表示/再試行
  - 履歴削除

## UI状態と挙動
- **Idle**: Startボタン有効、Stopは無効
- **Listening**: 収録中を表示、Stop有効
- **Thinking**: 処理中を表示
- **Speaking**: 再生中を表示、割り込みで停止
- **Error**: エラーメッセージ＋再試行導線を表示

## 主要UI要素
- **Start/Stop ボタン**
  - Startでマイク権限取得とセッション開始
  - Stopで音声入力/再生を停止
- **状態表示**
  - Listening / Thinking / Speaking を常時表示
- **通信境界表示**
  - `BOUNDARY_STATUS` 受信後に「RFC1918 + localhost」を表示
  - 取得前は「取得中」表記
- **チャットログ**
  - ユーザーの文字起こしとアシスタント応答を時系列で表示
  - 表示対象はセッション内の最新N件（Nは後決め）
- **合成音声**
  - 最新応答の音声を再生できる
  - 最新応答の音声をダウンロードできる
- **エラー表示**
  - エラー内容と対処方法を表示
  - 再試行ボタンを提供
- **履歴削除**
  - ローカル保存の会話履歴を削除

## チャット表示のデータ構造（UI視点）
- **User**: 文字起こしテキスト（partial/finalは最終のみ表示）
- **Assistant**: 応答テキスト
- **Audio**: 応答に対応する音声（最新のみ再生/ダウンロード）

## 非ゴール（UI）
- 複数画面/複雑なナビゲーション
- デザインシステム導入
- 詳細な会話ログ閲覧
