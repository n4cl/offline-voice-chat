# ワイヤーフレーム（テキスト）

## 画面構成（1ページ）

```
┌─────────────────────────────────────────────────────────────┐
│ Header                                                      │
│ - Title                                                     │
│ - (右側) 接続/状態                                          │
│ - (小) 計測値（ASR/LLM/TTS）                                │
├─────────────────────────────────────────────────────────────┤
│ Chat Log (中央カラム)                                       │
│ - Assistant メッセージ（左寄せ）                            │
│ - User メッセージ（右寄せ）                                 │
│ - 時刻/ステータス（小さく）                                 │
│                                                             │
│ （ログは縦スクロール、最新が下）                           │
├─────────────────────────────────────────────────────────────┤
│ Input Bar（固定・下部）                                     │
│ [＋] [テキスト入力..................................][送信] │
│                                            [音声入力開始/停止]│
└─────────────────────────────────────────────────────────────┘
```

## 状態メモ
- 送信は「送信」ボタンで実行
- 音声入力は右端ボタンで開始/停止（2値）
- 状態表示はヘッダー右側（接続/状態）
- チャットは中央寄せ・左右バブル
