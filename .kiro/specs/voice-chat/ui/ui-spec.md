# UI設計（暫定）

## 目的
- 最小構成で音声対話を開始/停止できること
- 状態（待機/収録/処理/再生）を明示すること
- エラー時に復旧導線を示すこと

## 画面一覧
- **メイン画面（単一ページ / チャット形式）**
  - チャットログ（文字起こし・応答）を画面中央に配置
  - 画面下部に入力バー（テキスト入力 + 送信ボタン + 音声入力トグル）
  - 状態表示（Listening / Thinking / Speaking）
  - 計測値の簡易表示（ASR/LLM/TTSの処理時間、開発用の小さな表示）
  - 合成音声の再生/ダウンロード
  - エラー表示/再試行
  - 履歴削除

## UI状態と挙動
- **Idle**: 音声入力ボタンは「開始」表示
- **Listening**: 収録中を表示、音声入力ボタンは「停止」表示
- **Thinking**: 処理中を表示
- **Speaking**: 再生中を表示、割り込みで停止
- **Error**: エラーメッセージ＋再試行導線を表示

## 主要UI要素
- **入力バー（下部固定）**
  - テキスト入力フィールド（中央）
  - 送信ボタン（押下で送信）
  - 音声入力ボタン（開始/停止の2値トグル、入力欄右端）
  - IME変換中のEnterでは送信しない
- **音声入力ボタン**
  - 開始でマイク権限取得と音声入力開始
  - 停止で音声入力/再生を停止
- **状態表示**
  - Listening / Thinking / Speaking を常時表示
- **計測値の簡易表示（開発用）**
  - ASR/LLM/TTS の直近処理時間を小さく表示
  - 表示対象は currentGenerationId のみ
  - 全ステージが揃った時点で表示更新する
- **チャットログ**
  - ユーザーの文字起こしとアシスタント応答を時系列で表示
  - 表示対象は会話セッション内の最新N件（Nは後決め）
- **合成音声**
  - 最新応答の音声を再生できる
  - 最新応答の音声をダウンロードできる
- **エラー表示**
  - エラー内容と対処方法を表示
  - 再試行ボタンを提供
- **履歴削除**
  - ローカル保存の会話履歴を削除

## チャット表示のデータ構造（UI視点）
- **User**: 文字起こしテキスト（partial/finalは最終のみ表示）
- **Assistant**: 応答テキスト
- **Audio**: 応答に対応する音声（最新のみ再生/ダウンロード）

## 非ゴール（UI）
- 複数画面/複雑なナビゲーション
- デザインシステム導入
- 詳細な会話ログ閲覧
